# Web Application Vulnerability Assessment
Cyber Security Internship – Task 1

Author: Benedict Karaya

---

## Project Overview
This project presents a vulnerability assessment conducted on a deliberately vulnerable test web application.

Target Website:
http://testphp.vulnweb.com

The objective was to identify security vulnerabilities, analyze their risk levels, and recommend remediation strategies to improve the application's security posture.

---

## Tools Used

Nmap (Zenmap)  
Used for network reconnaissance, port scanning, and service discovery.

OWASP ZAP  
Used for automated vulnerability scanning of the web application.

Browser Developer Tools  
Used for manual inspection of HTTP headers, requests, and responses.

Canva  
Used to design and structure the final professional report.

---

## Methodology

1. Reconnaissance  
Performed network scanning using Nmap to identify open ports and services.

2. Automated Vulnerability Scanning  
Used OWASP ZAP to scan the web application and detect potential vulnerabilities.

3. Manual Analysis  
Inspected requests, responses, and security headers using browser developer tools.

4. Risk Classification  
Identified vulnerabilities were categorized as:
- High Risk
- Medium Risk
- Low Risk
